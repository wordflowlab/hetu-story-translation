# 开发发布与上架

使用 Node.js25 和 npm ci 固定依赖。构建先核验 vendor/sources.json，再编译静态 Schema 校验器、后端、React、Skill与功能清单。运行包带完整许可，不含作者数据或凭据，不执行安装脚本。

```bash
npm ci
npm run build
npm run check
npm run test:unit
npm run test:machine
npm run test:ui
npm run package
```

测试只使用隔离作品；HETU_SOURCE、HETU_TEST_BIN、HETU_TEST_PACKAGE 和 HETU_PACKAGED_APP 固定真实宿主与包路径。机器与正式安装分别取证。

发行固定源码提交、不可变Tag、运行包、归档及包摘要、许可和实际验收回执。下载后重新核验同一字节，再登记河图插件中心。功能、专业数据和方法由本包维护；宿主只维护公共发现入口。安装、发布和作者业务决定分别授权，不用发行权限代替创作采纳。
