# 界面与交互设计

独立专业页面撑满可用窗口，左上返回，标题、刷新和“让AI处理”同排。宿主顶部与左侧不重复占据空间。页签为：源译对照、术语表、翻译问题、覆盖与更新、接续创作。优先呈现可读文本、对照、来源及专业图形，技术引用收进详情；不以JSON代替普通审阅。

复用宿主 Radix 色板、静态渐变和轻透表面，正文与输入稳定实色；字号12／14／20px、0.5px边框，默认无动画。浅暗、窄窗、减少透明度同步。图形有等价列表。

空状态可直接交接Agent。加载、来源缺失、部分完成、失败、冲突、unknown与成功分别呈现。手动编辑为可选高级入口，冲突保留编辑内容与固定基线；关闭重开恢复草稿和原操作。每一主要专业动作提供可用的GUI审阅入口和机器路径。
